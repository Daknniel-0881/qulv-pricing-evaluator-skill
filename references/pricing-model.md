## 一、5 大公理(决策骨架)

### 公理 1: 价值定价 > 成本定价 > 时间定价

**为什么时间定价是死路**: "老师人天 ¥1500/天" 永远卷不过新东方/达内 ¥800/天, 卷不过 985 应届生 ¥600/天。客户拿你和外包比,你永远输。

**正确做法**: 用客户视角算价值, 报价 = 价值的 5-15%。

```
客户用 AI 替代 1 个 ¥1.2 万/月人力 → 年化省 ¥14.4 万 → 你报 ¥3-5 万合理
客户用 AI 提升销售转化 5% × 月 GMV ¥500 万 → 年化提 ¥300 万 → 你报 ¥30-50 万合理
客户用 AI 避免一次客诉损失 ¥100 万 → 你报 ¥10-15 万合理
```

### 公理 2: 三档同时报(Anchor-Decoy 结构)

**为什么单一报价死**: 客户没有比较锚点, 只能自己定价, 必砍。

**正确做法**: 永远三档(启航 / 远航 / 旗舰), 旗舰是 anchor(99% 不卖), 远航是 decoy(80% 客户落点), 启航是 fallback(降级保命)。

| 档位 | 作用 | 实际成交率 |
|------|------|-----------|
| 旗舰(高) | Anchor, 让远航看起来便宜 | 5% |
| 远航(中) | Decoy, 80% 客户落点 | 65% |
| 启航(低) | Fallback, 降级保命 | 30% |

### 公理 3: 锚定先行(永远先报最高档)

**为什么不报底价**: 砍价空间不留, 没法谈。

**正确做法**:
- 客户问"多少钱" → 反问"你的核心痛点是什么 / 你预期解决什么问题"
- 客户给画像 → 直接报旗舰版价格 + 简单介绍
- 客户说"贵" → 拿出远航版"那这个版本可能更适合"
- 客户还想压 → 拿出启航版"再低就是 MVP 了, 我可不能不负责任地报"

### 公理 4: 续约钩子必谈(Fractional CAIO 机制)

**为什么项目结束 = 客户流失**: 一次性成交,客户拿走 deliverable, 你失去 LTV。

**正确做法**: 任何项目交付前 30 天, 必须铺垫 Fractional CAIO 月费续约。
- 月费 ¥3.8-6.8 万
- 年化 ¥45-80 万/客户
- 续约率目标 ≥ 40%
- 客户终身价值 = 项目价 × 3+

### 公理 5: 大单走阶段化拆分(三段式)

**为什么大单一锅卖必死**: 客户决策门槛高, 一次签 ¥80 万吓走人。

**正确做法**: 拆三段, 每段独立可结
- 阶段 1 诊断: ¥10-30 万, 1-2 月, 输出诊断报告 + 转型规划
- 阶段 2 战略: ¥20-50 万, 2-4 月, 输出转型路径 + Pilot 选择
- 阶段 3 落地: ¥30-100 万, 4-12 月, 输出 Pilot 实施 + 内化沉淀

每段都是新 SOW, 客户每段满意才进下一段。砍价空间从单单 ¥80 万→ 单段 ¥10-30 万,容易多。

## 二、5 大定价模式

### 模式 1: 价值定价(Value-Based Pricing)

**适用**: 战略咨询 / 转型规划 / 有明确可量化 ROI 的项目

**公式**: 报价 = 客户解决问题价值 × 5-15%

**操作流程**:
1. 客户访谈算 ROI: "你这个问题不解决,一年损失多少 / 解决了一年赚多少"
2. 算 5-15% 区间: 上限 15%(客户付得起), 下限 5%(自己利润够)
3. 三档报价: 启航 5%, 远航 10%, 旗舰 15%
4. 锚定: 价值 × 15% 当 anchor

**案例**:
- 客户: 制造业, 想用 AI 优化排产, 每月产能浪费 ¥50 万 = 年化 ¥600 万
- 启航(¥30 万 = 5%): 诊断 + 排产工具 1 个
- 远航(¥60 万 = 10%): 诊断 + 排产工具 + 3 个月陪跑
- 旗舰(¥90 万 = 15%): 诊断 + 排产工具 + 12 个月陪跑 + Fractional CAIO

**风险**: 客户不认账价值估算 → 必须用真实数据(对方提供 / 第三方报告)

**失败模式**: 自己拍脑袋估值 → 客户不买账。永远让客户参与算账。

### 模式 2: 套餐定价(Package Pricing)

**适用**: 标品(培训 workshop / 单品 Skill 定制 / 战略诊断包) + 中小企业

**公式**: 标准三档 + 加购菜单

**核心套餐(2026)**:

| 套餐 | 价格 | 适合 | 包含 | 工期 |
|------|------|------|------|------|
| **启航** | ¥3.8 万 | 中小企业试水 | 1 次 AI 诊断 + 1 个 Skill 工具 + 1 次 workshop | 4 周 |
| **远航** | ¥8.8 万 | 中小企业全面试 | 启航全部 + 3 个 Skill + 月度 1V1 陪跑 × 2 月 | 8 周 |
| **旗舰** | ¥18.8 万 | 中型企业完整 | 远航全部 + Agent 系统 + 季度陪跑 + Fractional CAIO 1 个月 | 12 周 |

**加购菜单(5 类 14 模块)**:

A. 培训类:
- A1 高管 workshop 1 场 ¥3 万
- A2 全员普及 1 期 ¥5 万
- A3 岗位定制培训 1 个岗位 ¥4 万
- A4 培训年框 ¥30-80 万

B. 工具类:
- B1 Skill 单品 1 个 ¥1.5 万
- B2 Agent 系统 1 个 ¥8-15 万
- B3 平台化开发 ¥30-100 万

C. 陪跑类:
- C1 月度 1V1 陪跑 ¥1.5 万/月
- C2 季度陪跑 ¥3.98 万/季
- C3 Fractional CAIO ¥3.8-6.8 万/月

D. 教育类:
- D1 内训学员包 5 人 ¥2 万
- D2 公开课 1 期 ¥3-5 万

E. 落地类:
- E1 转型规划 ¥5-15 万
- E2 Pilot 实施 ¥10-50 万

**操作**: 三档套餐 anchor + 加购菜单上推, 客单从 5 万 → 18 万的杠杆。

### 模式 3: 订阅定价(Subscription Pricing)

**适用**: 持续服务 / Fractional CAIO / 月度陪跑 / 长期顾问关系

**Fractional CAIO 月费档位**:

| 档位 | 月费 | 内容 | 频次 |
|------|------|------|------|
| 标准 | ¥3.8 万 | 1V1 周会 1 次 + 月度战略复盘 + 邮件支持 | 4 次/月 |
| 加强 | ¥5.8 万 | 标准 + 双周高管会 + Slack 即时支持 + 季度 workshop | 6 次/月 |
| 全能 | ¥6.8 万 | 加强 + 落地实施监督 + 团队 1V1 教练 + 全员答疑 | 8 次/月 |

**年化客户终身价值**:
- 月费 × 12 = ¥45.6 / 69.6 / 81.6 万
- 续约率 40-60% → 客户终身价值 = 月费 × 12 × 2-3 = ¥90-240 万

**风险**: 客户用量管理 — 限制响应时间, 否则被拖死

**话术**: "我不是工具人,你不能 24/7 找我。我是你的战略副手, 我们每周 1 次 1V1, 紧急事项 SLA 24 小时内响应。"

### 模式 4: 项目定价(Project-Based)

**适用**: 工具定制 / Agent 系统 / 平台化开发

**公式**: 阶段化里程碑 + 50/30/20 付款

**结构**:
- 30% 预付(开工前)
- 30% 里程碑 1 验收(中期)
- 20% 里程碑 2 验收(交付前)
- 20% 验收尾款(上线 30 天稳定后)

**SOW 必含**:
- 范围(scope): 列功能清单, 不在清单内 = 加价
- 节点(milestone): 4 个里程碑 + 验收标准
- 时间(timeline): 总工期 + 各节点时间
- 报价(price): 三档(MVP / 标准 / 完整)
- 退款(refund): 哪些情况退多少

**Scope creep 防御**:
- 明确写: "新增需求按加购菜单单独计价"
- 客户喊"再加一个" → 拿加购菜单加单
- 严控范围, 不"顺手帮忙"

### 模式 5: 效果定价(Performance-Based)

**适用**: 高对赌项目 / 销售 GMV / 客户获取成本(CAC) / 量化 KPI 明确

**公式**: 基础费(50%+) + 分润(50%-)

**典型结构**:
- 基础费: 锁定基本工时 + 工具成本(必须保 ≥ 50%, 否则白干)
- 分润: 销售 GMV 提升的 X% / 节省成本的 X% / 转化率提升的 X%
- 上限: 设 cap, 否则客户做大了你拿不动
- 时长: 12 个月起,短了拿不到钱

**典型对赌**:
- 客户: 想用 AI 提销售转化率从 5% → 8%
- 基础费 ¥30 万(必付)
- 分润: 月度 GMV 增量 × 10%, cap ¥80 万/年
- 客户达成 8% → 你拿 ¥30 万 + ¥30-80 万 = ¥60-110 万
- 客户没达成 → 你只拿 ¥30 万(必付)

**风险**:
- KPI 归因: 增量是不是因为你? 必须有 baseline + 对照
- 数据真实性: 客户报数据有水分? 必须第三方监测
- 时间长: 12 个月才回款 → 现金流压力

**何时不接对赌**: 客户从未做过该业务 / 数据不透明 / 决策权不在你 / cap 拉不下来

## 四、客户分层 × 价格倍数 × 应对策略

### 客户类型 1: 中小企业(<50 人 / 营收 <5000 万)

**特征**:
- 决策快(1-2 周)
- 预算紧(年 IT 预算 5-30 万)
- 决策人 = 老板, 一句话定案
- 弹性差: 砍 10% 是底线, 砍 30% 退案

**价格带**:
- 启航 ¥3.8 万 / 远航 ¥8.8 万 / 旗舰 ¥18.8 万

**应对策略**:
- 直接报三档套餐
- 30% 预付, 50/30/20 节奏
- 强调案例和速度("1 个月看到效果")
- 必铺 Fractional CAIO 续约

**风险**:
- 老板朝令夕改: 合同里写 scope, 加单按加购菜单
- 预算抠门: 用 AI 教育包(¥2-4 万)切入, 转化为陪跑
- 决策快但执行慢: 必须 KPI 化, 否则项目烂尾

### 客户类型 2: 中型企业(50-500 人 / 营收 5000 万-5 亿)

**特征**:
- 决策中(1-2 月)
- 预算中(年 IT 预算 50-300 万, AI 占 30-100 万)
- 决策人 = COO/CTO/CDO 或老板, 中层有评估意见
- 主力市场, 价格弹性正常

**价格带**:

## 十、失败案例 + 合同陷阱

### 失败模式 1: "你先做了我再付"

**症状**: 客户说"先看效果再付钱""做出来我就买"

**结果**: 100% 烂尾。做完客户找借口("不太满意""老板说再看看")

**应对**: 必须 30% 预付。"我们流程就是这样, 30% 预付不变。如果你信不过我, 那不要紧, 我们也是要看客户能否合作。"

### 失败模式 2: 砍价 40%+

**症状**: 客户说"5 万行不行" 而你报价 ¥10 万

**结果**: 不仅利润没有, 还要被 PUA 降低交付质量, 最后双输

**应对**: 礼貌退案。"这个价格我没法保证交付质量, 不太合适。如果你预算紧, 启航版 ¥3.8 万更适合你。"

### 失败模式 3: scope creep 失控

**症状**: 客户每次说"再加一个""顺手帮我做下" 

**结果**: 工期翻倍, 利润为 0, 你疲于奔命

**应对**: SOW 写死 scope, 加单按加购菜单。"这个超出 SOW 范围, 我们走加购菜单 ¥X 万。"

### 失败模式 4: 多决策人扯皮

**症状**: COO 说要 A 方案, CTO 说要 B 方案, 老板说"再讨论"

**结果**: 项目搁置 3-6 个月,你白忙

**应对**: 锁定一个"决策人"。"我们项目需要一个 single point of contact, 通常是 CIO/CDO。所有决策从他这边出。其他人有想法走他汇总。"

### 失败模式 5: 国央企回款拖 18 个月

**症状**: 国央企财务说"等下次预算"

**结果**: 你现金流断裂

**应对**: 合同里写"逾期 60 天计息 0.05%/天", 实际帮你催。同时大单不要超过现金流的 50%。

### 合同陷阱(必须写进合同)

**必须有的条款**:
1. 范围(scope)详细列, 不在内 = 加价
2. 里程碑 + 验收标准(可量化)
3. 付款节点(30/30/20/20 节奏)
4. 退款条款(里程碑未达 → 已收按比例结)
5. 知识产权归属(交付物给客户, 通用方法论 / Skill 模板归你)
6. 保密协议(双向)
7. 不可抗力 + 终止条款
8. 仲裁地点(选你方便的城市)
9. 违约金(逾期 / 单方终止)

**避免的坑**:
- 不写 scope → 无限扩展
- 不写 milestone → 无法进度结算
- 不写退款 → 客户耍赖
- 不写 IP → 自己沉淀的方法论被客户独占
- 让客户用客户模板 → 全是客户单方面有利条款

## 十二、Hormozi Grand Slam Offer 价值堆叠公式 (v7.0)

> 来源: Alex Hormozi《$100M Offers》 · 适配场景: B 端报价单 / C 端训练营 / 超个定制三类报价

### 12.1 价值方程

```
                Dream Outcome × Perceived Likelihood of Achievement
   Value  =  ─────────────────────────────────────────────────────
                       Time Delay × Effort & Sacrifice
```

| 变量 | 含义 | 用户报价怎么写 |
|------|------|---------------|
| **Dream Outcome** ↑ | 客户最想要的结果 | 量化金额(省¥X / 多赚¥Y / 释放Z小时)、写客户**老板/老板娘的私人愿景**(早下班、IPO、上市) |
| **Perceived Likelihood** ↑ | 客户相信能成功的概率 | 案例锚定(同行 X 公司用我做完……)、退款承诺(交付不达标 7 日全退)、第三方背书 |
| **Time Delay** ↓ | 多快能见到结果 | "前 2 周出 1 个跑通工作流" / "30 天 4 个高频岗 SOP 落地" / "首期 ROI 在 90 天内可见" |
| **Effort & Sacrifice** ↓ | 客户要付出的精力 | 我们做什么 + 你只需要什么(decision time / 数据导出 / 1 周 1 次站会),不要"配置 IT 团队" |

### 12.2 Grand Slam Offer 五步打包(每个产品都套一遍)

1. **Dream Outcome**: 你想要的不是 AI,是 **「半年内省 1 个全职 + 多接 30% 单 + 老板早回家」**
2. **Stack(价值堆叠)**: 主交付 + 模板库 + 私董会 + 工具账号 + 紧急支援 → **明示总价值 ¥X,你今天只付 ¥Y**(Y 是 X 的 1/3-1/5)
3. **Risk Reversal(风险反转)**: 7 日无条件全退 / 不达 KPI 退一半 / Pilot 不付款 / 12 个月不见效退预付定金 50%
4. **Scarcity(稀缺)**: 季度只接 N 家(N=3-5,真实) + 截止日(月底前签约价 X,下月 X+20%)
5. **Bonus(赠品)**: 报价单顶上 "限本月签约赠送" → 12 节训练营 / 1 次年度 workshop / Slack 群常驻 / 行业报告

### 12.3 反向使用 — 砍价当下背诵

客户砍价时,不是降价,是**重申方程**:
- "我们降价等于降 Dream Outcome → 您拿到的不是 AI,是省下的人天和不丢单"
- "我们不能改 Time Delay(2 周首跑通),不能改 Effort(您只出 1 周 1 次站会),所以单价不变"
- "如果您坚持 ¥X,我们可以减一个模块(明示砍掉哪块价值),不能直接打折"

## 十七、合同 8 条款必含审查清单 (v7.0 法律红线)

> 来源: GPT-Pro v3 调研 + Claude v3 法律建议
> **任何 ¥10 万以上的合同必跑这 8 条**, ¥30 万以上必请法律顾问 review

| # | 条款 | 必含要点 | 风险点 |
|---|------|---------|--------|
| 1 | **Scope of Work** | SOW 清单 + 不在范围内的明列 + 范围变更走变更单 | 客户口头加需求不付款 |
| 2 | **IP / Ownership** | 客户拥有"业务数据" + 我们拥有"工具底座 / 通用 Skill / 框架" + 客户禁止二次销售 | 客户拿你做的东西转手卖 |
| 3 | **Data / Privacy** | 数据脱敏 / 删除责任 / 跨境 / 数据安全法 / 仅项目期使用 | 数据泄露被诉 |
| 4 | **Payment / Schedule** | 30/40/30 三段付款 / 逾期 0.05% 日息 / 30 日起诉 | 客户拖款 |
| 5 | **Refund / Termination** | KPI 不达标退一半 / 不可抗力分摊 / 提前终止结算 | 客户要求全退 |
| 6 | **NDA / Confidentiality** | 双向保密 + 期限 5 年 + 违约金 ¥50-100 万 | 商业机密泄露 |
| 7 | **Liability Cap** | 责任上限 = 项目总价 100% / 间接损失免除 | 千万赔偿索赔 |
| 8 | **Force Majeure / 不可抗力** | 政策变化 / 战争 / 疫情 / 模型 API 中断 → 顺延非违约 | API 涨价 / 监管禁止 |

## 十八、学员变员工双层架构合规 (v7.0 法律避险)

> 来源: Claude v3 法律分析 · 学徒制最大坑是"事实劳动关系"

### 18.1 双层结构

```
第一层: 培训关系 (Training Layer)
  ├ 学员付学费 ¥3,980-9,800
  ├ 我们交付: 课程 + 答疑 + 1 个实战练习项目
  └ 关系: 教育合同, 不是劳动合同
        ↓ 自愿升级
第二层: 项目协作合同 (Collaboration Layer)
  ├ 学员从教育合同毕业
  ├ 改签项目分包合同 / 自由职业合同 / 短期项目协议
  ├ 学员收"项目分润" 不是"工资"
  └ 关系: 商业合作, 非劳动关系
```

### 18.2 三件套(每个学员入营必签)

1. **培训合同**(主合同, 约束教育关系)
   - 明示: "本合同为培训服务合同, 不构成劳动 / 雇佣 / 派遣关系"
   - 明示: "结业不保证就业 / 不保证项目分包 / 不保证收入"
   - 学员任务范围: 仅"辅助性"任务(资料整理 / 测试 / 内容草稿 / 用户访谈), **不得参与核心交付**

2. **NDA**(全期间 + 离营后 5 年)
   - 客户信息 / 项目细节 / 报价 / 内部 SOP / 工具底层 → 全部禁止外传
   - 违约金: ¥50-100 万 / 起诉地: 我方所在地

3. **学员任务边界书**(单独文件, 结业前签)
   - 明列哪些任务允许学员触碰, 哪些不允许
   - 客户敏感数据(财务 / 客户名单 / 商业机密)禁止接触
   - 学员产出物的所有权归用户, 学员可署名但不可商用

### 18.3 法律红线(违一条 = 立即停)

- ❌ 营销文案出现"包就业 / 包分包 / 转正"(招转培刑事红线)
- ❌ 学员长期无偿干活(超 1 月)未升级到分包合同(事实劳动关系)
- ❌ 学员干"客户核心交付件"(SOW 主交付物)(劳动关系认定信号)
- ❌ 学员被指派固定工时 / 固定坐席 / 受日常考核(劳动关系信号)

## 十九、三条收入线模型 (v7.0 现金流战略)

> 不是"先做哪条", 是"三条同时跑, 互相喂"

### 19.1 现金流线 (C 端社群 + 训练营)

- 目的: 解决短期现金流, 月续费收入稳基本盘
- 产品: ¥99-399 社群 / ¥3,980-9,800 训练营 / ¥6,999 AI 门诊
- 利润率: 70-85%
- 月预期: ¥2-8 万 (M1-3) → ¥5-15 万 (M4-12)
- 触达漏斗: 公众号 / 小红书 / 视频号 / Newsletter

### 19.2 能力线 (学员变员工)

- 目的: 用学员补人手 + 训练成准员工 + 卖更大单
- 产品: 训练营内部"战友筛选" → 项目分包合同 → 团队成员
- 收入逻辑: 不是收入,是**降低 B 端单的交付成本** → 同样客单利润 +30-50%
- 月预期: M3 起放大 B 端利润, M6 起接 ¥30+ 万单不卡人手

### 19.3 升级线 (B 端陪跑 / 大单)

- 目的: 利润主力 + 长期 LTV
- 产品: ¥1.98-12.8 万快搭包 → ¥30-80 万年框 → ¥80-300 万陪跑
- 利润率: 40-65%
- 月预期: ¥3-15 万 (M1-6) → ¥30-100 万 (M7-12)
- 触达: 内容驱动 + 客户介绍 + 招投标 + AI 门诊转化

### 19.4 三线协同(关键!)

```
现金流线 ──喂──> 能力线 ──喂──> 升级线 ──喂回──> 现金流线
   ↑                                              ↓
   └──── 客户案例 + 学员证言 + 内容素材 ──────────┘
```

- 现金流线**养活**前 6 个月不缺粮
- 能力线**降低**升级线的交付成本
- 升级线**反哺**现金流线的内容(案例 / 数据 / 学员素材)
- 三线缺一: 缺现金流 → 撑不到大单 / 缺能力 → 大单接不动 / 缺升级 → 没利润空间
