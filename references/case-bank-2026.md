# B 端 AI 业务同行案例库 2026

> **用途**: 给客户报价前找锚点案例, 对照同行价格带和服务结构, 避免低估自己。
> **数据来源**: `Bridge/pricing-system/raw/` (00-资产盘点 / 02-国内 AI / 03-传统咨询 / 04-国外 AI / 05-企业内训) + `Bridge/pricing-system/research-v2/` (01-垂直行业 / 02-独立顾问 / 03-中型咨询 / 04-甲方采购 / 05-混合定价 / 06-失败案例) + GPT Pro 深度调研 + Claude 深度调研 综合。
> **时间口径**: 2024-2026 年同行成交价/挂牌价。所有数字标注【挂牌】/【成交】/【传闻】区分可信度。
> **使用方式**: 报价前按"客户类型 + 业务线"快速检索对应锚点价格带。

## 9. 锚定价使用 SOP

### 9.1 报价前检索 SOP

1. **客户问"多少钱"** → 不直接报, 先问客户类型(中小/中型/上市/国央企)
2. **找对应同行案例** → 翻本文件, 找 2-3 个同档位同行的报价
3. **拉锚定** → "您这类客户, 麦肯锡是 ¥500-3000 万, 我们做到 ¥30-50 万, 性价比是核心卖点"
4. **三档报价** → 启航 / 远航 / 旗舰, 给客户选择空间

| "降一点吧" | "我们已经只取 MBB 1/10, 不能再砍" |

### 9.3 案例库更新机制

- **每月更新**: 新看到的同行案例补充到本文件
