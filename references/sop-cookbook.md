# B 端 AI 业务 SOP 模板库

> **用途**: 报价单 / SOW / 对赌 / KPI / 退款条款 / 续约信 等核心商务文档的模板库, 直接套用。
> **使用方式**: 客户进入"准签"阶段, 按业务类型快速定位模板, 改名改数字直接交付。
> **核心原则**: 文字模板 = 法律保护 + 商务边界。所有口头承诺都必须落到模板里。

```markdown
> 注: 量化 KPI 仅适用于"效果对赌"档的项目。基础项目不强制 KPI。

---

### 2. 项目范围(In Scope)

#### 2.1 交付物清单
- 交付物 1: [描述] (Owner: 我们, Due: [日期])
- 交付物 2: [描述] (Owner: 我们, Due: [日期])
- 交付物 3: [描述] (Owner: 我们, Due: [日期])
- 交付物 4: [描述] (Owner: 客户, Due: [日期])

明确不在本项目范围内的事项, 避免 scope creep:
- [Item A]: 单独立项, ¥X 万
- [Item B]: 单独立项, ¥Y 万

> Out of Scope 是 scope creep 防御的核心条款, 必须列详尽。
```

## 3. 对赌协议模板

### 3.1 适用场景

- 客户要求"无 KPI 不付钱"
- 客户提出"我们要看效果"
- 客户业务 GMV / 营收 / 转化率等可量化
- 客户预算充裕(¥30 万+)

### 3.2 对赌协议模板

```markdown

- 基础费: ¥[50] 万 (50%) — 工时成本, 无论 KPI 是否达成都付
- 业绩分润: ¥[50] 万 (50%) — 基于 KPI 达成情况

### 2. KPI 达成 与 分润

| KPI 达成情况 | 业绩分润 |
|-----------|--------|
| 达成 100% 目标 | ¥50 万 (100%) |
| 达成 80%-99% | ¥40 万 (80%) |
| 达成 50%-79% | ¥30 万 (60%) |
| 达成 30%-49% | ¥10 万 (20%) |
| 达成 < 30% | ¥0 (0%) |

### 3. KPI 监测

- KPI 数据来源: [客户的 ERP / CRM / 仪表板]
- 监测周期: 项目结束后 6 个月内
- 第三方监测: [行业协会 / 数据公司] 验证(可选)

- 项目结束 6 个月后, 按 KPI 完成度按 30 天内支付

- 第三步: 仲裁

### 6. 退款情况

- 客户中途退出: 已交付部分按实际工时结算 + 退还 50% 未交付部分

### 7. 双方义务

#### 客户义务
- 提供完整业务数据
- 配合 KPI 监测
- 不暗中破坏 KPI

#### 我方义务
- 按 SOW 完整交付
- 提供数据收集和分析支持
- KPI 达成情况和分析报告
```

## 4. KPI 设计指南

### 4.1 KPI 选择原则

| 维度 | 好的 KPI | 差的 KPI |
|------|---------|--------|
| 量化 | 可数字化 | 主观判断 |
| 客观 | 第三方可验证 | 内部说了算 |
| 时间 | 项目期内可达 | 长期才能验证 |
| 归因 | 可归因到 AI | 多因素混杂 |

### 4.2 不同业务的 KPI 模板

#### 销售/营销
| KPI | 计算方式 | 数据来源 |
|-----|---------|--------|
| GMV 增量 | 项目期 vs 同期前 | CRM |
| 转化率 | 转化率 vs 基线 | CRM |
| LTV | 单客户 LTV | CRM/ERP |
| 客单价 | 平均客单 | CRM |

#### 客服/客户体验
| KPI | 计算方式 | 数据来源 |
|-----|---------|--------|
| 响应时间 | 平均响应秒数 | 客服系统 |
| 满意度 | NPS / CSAT 分数 | 调研 |
| 一次解决率 | 一次解决率 % | 客服系统 |
| 客服效率 | 单位时间处理量 | 客服系统 |

#### 内容/营销
| KPI | 计算方式 | 数据来源 |
|-----|---------|--------|
| 内容产量 | 单位时间内容量 | CMS |
| 阅读量 | 月度阅读量 | 公众号 |
| 转化量 | 阅读到转化的比例 | CRM |
| 内容 ROI | 内容生产 ROI | 综合 |

#### 运营/效率
| KPI | 计算方式 | 数据来源 |
|-----|---------|--------|
| 单位时间产出 | 输出/时间 | ERP |
| 错误率 | 错误数/总数 | ERP |
| 成本节约 | 项目前后成本 | 财务 |
| 人均效能 | 人均产出 | HR |

### 4.3 KPI 设置避坑

- ❌ 不要"客户满意度 + 战略对齐"这种主观 KPI
- ❌ 不要"GMV 增长 50%" 没有锚点
- ❌ 不要"3 个月内做到 1000 万" 没有归因
- ✅ 要"项目期内, 同期 GMV 同比增长 X%"
- ✅ 要"项目期内, 转化率从 Y% 提升到 Z%"
- ✅ 要"项目结束后 6 个月内, ROI 达 200%"

## 5. 退款条款模板

### 5.1 标准退款条款

```markdown
### 退款条款

#### 5.1 客户主动退款

| 退款时点 | 退款比例 |
|---------|--------|
| 合同签订前 | 100% (含预付款) |
| 合同签订后 7 天内 | 95% (扣 5% 启动费) |
| 项目启动 (Kick-off) 后 30 天内 | 已交付部分按实际工时结算, 未交付 70% 退 |
| 中期里程碑后 | 已交付按合同结算, 未交付 50% 退 |
| 终交付后 | 不退款(交付物已交付) |

#### 5.2 我方违约退款

| 违约情况 | 退款比例 |
|---------|--------|
| 我方逾期超 30 天 | 已支付的 100% + 违约金 5% |
| 我方放弃项目 | 已支付的 100% + 违约金 10% |
| 我方交付物不达标 | 修订或退 30% 工时费 |

#### 5.3 双方共同终止

如双方协商一致终止合同:
- 已交付部分按实际工时结算
- 未交付部分按 70% 退还(我们保留 30% 启动成本)

#### 5.4 不可抗力

- 天灾 / 战争 / 政府要求等不可抗力, 双方按实际工时结算
- 双方均无违约责任
```

### 5.2 适用场景说明

- 启航包(¥3.8 万): 简化退款条款, 重点是"7 天后不退"
- 远航包(¥8.8 万): 标准条款 + 中期里程碑保护
- 旗舰包(¥18.8 万)+: 完整条款 + 第三方监测兜底

## 13. 合同 8 条款模板库 (v7.0 法律红线)

> 来源: GPT-Pro v3 + Claude v3 第二轮调研 · 法律避险标准库
> **使用规则**: ¥10 万+ 合同必跑这 8 条 / ¥30 万+ 必请法律顾问 review / ¥80 万+ 必走律所审核

### 13.1 条款 1 — Scope of Work (SOW)

```
甲方需求范围以《SOW 附件》为准, 含:
① 交付物清单(逐项明列, 含数量 / 规格 / 验收标准)
② 工期(含里程碑节点)
③ 不在范围内的事项(明列以下不属于本合同范围: 客户系统集成 / 跨平台改造 / 第三方 SaaS 接入 / ……)
④ 范围变更必须以书面《变更单》为准, 单方口头要求无效, 变更价不低于 ¥X 万
```

**风险点**: 客户口头加需求不付款 → 必须有变更单机制

### 13.2 条款 2 — IP / 知识产权

```
① 项目交付的【业务数据 + 业务定制部分】所有权归甲方
② 乙方拥有【工具底座 / 通用 Skill / Prompt 框架 / 内部 SOP / 培训内容】完整 IP, 仅授权甲方在其业务范围内使用
③ 甲方禁止将本项目交付物以"产品 / SaaS / 服务"形式二次销售
④ 乙方保留以"客户案例 / 论文 / 公开演讲"形式引用本项目的权利, 数据脱敏后使用
⑤ 任何 IP 争议适用 [所在地] 法院管辖
```

**风险点**: 客户拿你做的东西转手卖 / 客户禁止你写案例

### 13.3 条款 3 — 数据 / 隐私

```
① 甲方提供数据仅用于本项目, 项目结束后乙方在 30 日内删除并书面确认
② 数据脱敏责任由甲方承担, 乙方无义务核查脱敏完整性
③ 乙方采用业界标准加密存储, 但不对【超出合同范围的数据泄露】承担责任
④ 跨境传输数据需经甲方书面同意, 适用《数据安全法》《个人信息保护法》
⑤ 项目期间发生数据安全事件, 双方共同评估责任比例
```

**风险点**: 数据泄露被诉 / 跨境合规

### 13.4 条款 4 — 付款 / 进度

```
分期付款表:
① 合同签订 5 日内: 30% 预付款 ¥X 万
② 中期里程碑(M2 验收通过)5 日内: 40% 中期款 ¥X 万
③ 终验收通过 5 日内: 30% 尾款 ¥X 万

逾期处理:
① 任何一期逾期 ≥ 7 日, 乙方有权暂停服务
② 逾期 ≥ 30 日, 按未付款 0.05% / 日计违约金, 累计上限 30%
③ 逾期 ≥ 60 日, 乙方有权终止合同并起诉, 已交付部分按比例结算
```

**风险点**: 客户拖款 / 不付尾款

### 13.5 条款 5 — 退款 / 终止

```
退款机制:
① 启动 7 日内甲方主动终止 → 全额退还预付款(扣除 ¥X 万启动成本)
② 阶段性 KPI 不达标(明列具体 KPI 数值)→ 退还该阶段款项的 50%
③ 乙方主动违约 → 全额退还未交付部分款项 + 实际损失补偿(上限合同总额 50%)

终止机制:
① 任何一方提前终止需提前 15 日书面通知
② 不可抗力导致无法继续 → 双方协商,已交付按比例结算
③ 终止后 IP / 数据 / 保密义务继续生效 5 年
```

**风险点**: 客户要求全退 / 提前终止纠纷

### 13.6 条款 6 — NDA / 保密

```
保密范围(双向):
① 甲方: 客户名单 / 内部数据 / 业务流程 / 财务信息 / 合同条款
② 乙方: 工具底层 / Prompt 模板 / 内部 SOP / 报价细节 / 学员名单

保密期限: 合同期内 + 合同终止后 5 年

违约金: 单次违约 ¥50-100 万 + 实际损失补偿
起诉地: 乙方所在地法院

例外: 法律强制要求 / 公开信息 / 经书面同意的披露
```

**风险点**: 商业机密泄露 / 客户名单外流

### 13.7 条款 7 — 责任上限

```
① 乙方对本合同的最大责任 = 合同总价 × 100%
② 间接损失(商誉损失 / 业务中断 / 利润损失 / 第三方索赔)免除
③ 不可抗力 / 客户原因导致的损失乙方不承担
④ 严重故意 / 重大过失不适用本责任上限
```

**风险点**: 千万赔偿索赔 / 客户连带损失

### 13.8 条款 8 — 不可抗力

```
不可抗力情形包含但不限于:
① 政策变化(AI 监管 / 模型 API 禁令 / 跨境政策)
② 战争 / 疫情 / 自然灾害
③ 第三方平台不可预见的服务中断(OpenAI / Anthropic / 阿里云模型 API 不可用 ≥ 7 日)
④ 法律新规导致服务无法继续

处理:
① 受影响方 7 日内书面通知, 工期顺延
② 持续 ≥ 30 日 → 双方协商重新签订或终止
③ 顺延期间不计违约
```

**风险点**: API 涨价 10x / 监管禁止特定服务
